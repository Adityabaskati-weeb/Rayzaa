# Rayzaa 16-Hour MVP Scope

## Must Build

- seeded live transaction stream
- feature extraction service
- one real fraud scoring path
- graph-risk heuristics
- profile-drift scoring
- decision engine
- case investigation drawer
- explanation panel
- analyst actions: approve, review, block, escalate

## Should Build

- risk distribution panel
- geo risk heatmap
- suspicious ring graph view
- threshold controls for risk bands
- feedback buttons for false positive / confirmed fraud

## Optional Wow Features

- animated graph expansion on suspicious events
- AI-generated analyst brief from SHAP signals
- replay mode for a scripted attack sequence
- device trust visualization
- drift queue with reclassification suggestions

## Fake or Simulated for Demo

- voice biometric verification result
- real device attestation
- RL-based threshold adaptation
- continuous retraining job
- downstream AML/KYC case-management integration
- full loan re-underwriting workflow

## Post-Hackathon Scale Features

- trained graph neural network
- robust feature store
- Kafka or managed event bus
- full model monitoring and drift tracking
- human-in-the-loop review audit logs
- automated retraining and evaluation pipeline
- production identity and access controls

## Time Discipline Rules

- If the core stream is not working, stop adding new surfaces.
- If graph visualization is not working, simplify the graph before adding more models.
- If the dashboard looks generic, improve motion and hierarchy before adding extra charts.
- If model latency threatens the demo, use cached outputs for hero cases.
