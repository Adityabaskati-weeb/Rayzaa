# Data Strategy

Rayzaa should blend seeded realism with controlled demo storytelling.

## Recommended Sources

- IBM AML-style transaction patterns for structural realism
- synthetic UPI-style event generation for product-specific flavor
- handcrafted fraud-ring scenarios for graph demos
- lightweight drift narratives for reclassification cases

## Suggested Subfolders

- `raw/`: source data and references
- `processed/`: cleaned tables and cached features
- `synthetic/`: generated stream payloads and hero cases

## Demo Principle

Random data creates noise. Seeded scenarios create memorable demos.

Use live generation for background activity and precomputed showcase cases for:

- burst fraud rings
- shared device clusters
- dormant account reactivation
- geo jump anomalies
- suspicious merchant concentration
